## 联调前置条件（非接口问题，但会阻塞）
1. 后端需 JDK 21 启动：`JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home ./mvnw spring-boot:run`
2. MySQL `second_hand_trading` 库需存在且表结构完整（建表见 `circleu.sql`）。
3. Redis / RabbitMQ / Sentinel dashboard 非必须（代码已做降级），但库存、延迟关单、限流功能依赖 Redis/MQ 时才生效。
4. 前端 `request.ts` 的 baseURL 需指向后端地址（默认 `localhost:8080`）。
